# IoT-Based Cardiac Health Monitoring Systems (Research Survey)

This repository contains my research contribution on **IoT-enabled cardiac health monitoring systems** using **ECG, PPG, and PCG signals**.  
The study reviews 40 research articles, highlighting the role of **wearable devices, wireless communication, cloud integration, and machine learning** in improving remote healthcare.

## 📄 Publication
**Title:** IoT-Based Cardiac Health Monitoring Systems using ECG, PPG and PCG Signals: A Comprehensive Survey  
  

## 🧑‍🔬 My Role
- Conducted data-driven research and literature review  
- Analyzed IoT architectures, biomedical signal processing methods, and ML algorithms  
- Co-authored and structured the final publication
